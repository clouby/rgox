RGOX is a command-line interface (CLI) tool designed to help users run regular expressions efficiently. It provides a simple and intuitive way to test and apply regular expressions directly from your terminal.

## Installation

```bash
go install github.com/clouby/rgox/cmd/rgox@latest
```

## Usage

RGOX uses the [re2](https://github.com/google/re2/wiki/Syntax) regex syntax. Simply enter your regex pattern and test text to see matches and capture groups highlighted in different colors.
